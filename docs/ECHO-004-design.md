# ECHO-004 · 先选检索路径，再验证证据

ECHO-001 提供关键词索引和上下文长度估算。ECHO-002 将每个实验库绑定到一个人物。ECHO-003 追加事实复核，并用 Reflect 的现行版本、待重评状态和人审记录控制经验的可用性。ECHO-004 保留这些接口，将检索所需的元数据与原始记忆 ID 关联。目标是比较几种查找方法的收益与成本。

## 数据契约与退出方案

使用 `Atlas.create(source, destination, owner, verifier)` 显式启用。它以只读方式打开源文件，使用 SQLite 在线 backup API 得到一致的实验副本。在目标文件中增加关系表和索引，复用已有 FTS5 trigram 或执行原有的索引初始化。目标文件必须不存在，创建失败会清理本次产生的副本。对于已绑定人物的源库，人物必须匹配；旧版无人物字段的数据库需要宿主先确认所有权。打开已有 Atlas 使用 `Atlas(destination, owner)`。人物维度是记忆提及的对象，不能当作访问身份。

源库保留为回滚基准。回滚时停止使用实验副本，重新打开源库；如需留档，应单独保存实验期间新增的反馈与记录。该流程无写回或双向同步。副本生成后，源库上发生的新修订不会自动传播到副本，读取最新证据需要对同一实验副本提交修订或从新快照重建。测试检查源文件字节、已有目标拒绝、人物错配、构建失败清理和旧接口读取。[迁移测试](../tests/test_echo004.py)

候选在同一 SQLite 读快照内接受检查。发生修订的旧事实、撤销或过期的记录、条件不匹配项及被禁止的领域都会被排除。对重新分类的事件，旧叙述整体退出；宿主可单独登记最新核验事实。旧核验被后续核验替代时也退出。批准的派生记录必须能回查其依赖。遇到循环或超过 12 层的授权验证链会拒绝该候选。删除底层来源后，尚在的依赖引用使派生项验证失败。Atlas 的显式依赖不能由文本相似性推断，宿主须正确登记。

## 规划与回退

`Query(text, domain, as_of, conditions, feature)` 将授权域、判定日期、适用条件与任务文本分开。可信宿主确定上下文。文本支持 ISO 日期、日期区间、带引号的项目和相似事件，以及明确的“人物=”“项目=”“起点=”“关键词=”等字段。日期范围限定事件发生日，as_of 单独判断记忆有效期。当前实现不重建过去时点的权限或旧判断。

`Navigator.plan(query)` 在正文检索前输出任务类型、首选与备选路线、约束、置信度、Token 和毫秒预算及停止条件。问候跳过正文检索；日期走日期索引；人物/项目走分类交集；类似事件先查登记别名；有关依据链的问题在已验证的关系边上最多扩展两跳；其他事实优先走 ECHO-001 FTS。自然语言解析仅覆盖这些明确模式。调度器返回的数据记录没有命令执行能力。

默认最多 3 条路线，k=3，128 个估算 Token，搜索预算 150 ms。每路候选窗口为 12k，FTS 最多 100 条。SQL progress handler 及 Python 循环共同检查单调时钟。搜索时间预算不包含最后持久化审计所花的时间，也不是操作系统级实时保证。结果按完整证据条目打包，包含 ID 与分隔符。缺少必要依据的多跳结果不得以单条关键词命中替代。无合格结果或预算耗尽时返回 insufficient 或 deadline，置信度仅表达规划器的路线偏好。

## 可纠正的反馈

执行日志记录计划、每次尝试及原因、实际证据 ID、状态、搜索用时和估算 Token。结果正确与否由调用方另行提供独立验收依据，事前不可知。训练接口写入运行 ID、核验来源与标签集。集合完全命中且有输出才算该路线的正例。独立参考答案允许计算是否找到完整证据和误召回。空结果不奖励。实验中的盲测答案只在检索之后评分，不反馈给规划器。

自适应仅在同一任务类型的适用路线中排序，永远不能取消有效性检查或永久删除备选路线。读取最近 128 条有效反馈头，每个任务指纹和路线只计一次，每路最多使用 24 个样本。至少两个不同任务才改变优先级。评分为 (2+正确数)/(4+样本数)，速度不参与打分。错误评价通过引用上一版反馈 ID 改正或撤回。相同来源不得为不同任务背书。这个接口信任宿主对核验者的认证；数据库内的标签不具备身份认证能力，错误或串通的核验仍可影响排序。

```python
from echo_memory.atlas import Atlas
from echo_memory.navigator import Navigator, Query

atlas = Atlas("synthetic-atlas.sqlite", "synthetic")  # 已登记数据的实验副本
navigator = Navigator(atlas, adaptive=True)
query = Query("人物=桐舟 项目=赤塔", domain="met", as_of="2026-03-01")
plan = navigator.plan(query)
result = navigator.search(query)
```
