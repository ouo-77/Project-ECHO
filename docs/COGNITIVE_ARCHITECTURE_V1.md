# Project ECHO — 认知架构蓝图 v1.0

> 记忆保存过去，反思审视过去，学习改变未来；自主性来自有依据的选择，而不是无边界执行。

- **日期**：2026-11-10
- **来源**：项目方提供的认知架构蓝图，公开版省略个人署名。
- **文档状态**：研究蓝图 / Proposed；不代表所有模块已实现
- **项目**：https://github.com/ouo-77/Project-ECHO

## 1. 研究目标

探索 AI 智能体能否通过可追溯经历、长期记忆、反思、奖励和状态调节，形成连续、可解释、又可修正的行为模式。研究重点是可测量的行为改善，而非预设其拥有主观意识、真实快乐、痛苦或灵魂。

研究方向 **B+C**：B，允许基于证据的独立判断与异议；C，仅在显式授权、可撤销、有限预算下探索自主行动。

**禁止将亲近度、情感状态或奖励分数作为系统权限。** 不以最大化聊天时长、讨好用户、索取关注作为奖励目标。

## 2. 当前事实基线

- **ECHO-001（已有）**：SQLite 持久化、来源与修订记录、可选 FTS5、限定长度检索与合成评测。
- **ECHO-002（已有）**：根据已核验合成事件更新熟悉度、亲近度、领域可信度及模拟交互策略。
- **ECHO-003（已验证的离线原型）**：证据撤销与重放、三时间尺度调节、独立的 ECHO Reflect 与依赖失效保护。原顺序 288 个检验中修正后答对 219 个，但错误放行由 7 次增至 18 次。Reflect 在 40 个预设答案任务中答对 29 个，关闭时答对 25 个。[实验报告](../experiments/echo003/REPORT.md)
- **ECHO-004（本次实验）**：Memory Atlas 的多维索引与有限证据连接，以及 Memory Navigator 的规划、回退和可撤回的反馈。效果与成本以三组分规模对照为准。[实验报告](../experiments/echo004/REPORT.md)
- **ECHO-004.1** 在三个合成技术领域实验了语义规划、分级遗忘与基于独立试验的经验整理。122 道问题中返回正确证据集合 119 次。[实验报告](../experiments/echo0041/REPORT.md)
- **ECHO-005** 将 ECHO-003 的关系与时间投影接到离线语言模板。情境组在 44 个合成场景中正确识别 43 个，讽刺性批评仍有漏判。[实验报告](../experiments/echo005/REPORT.md)
- **待研究**：真实场景验证、奖励动机、有限主动探索、在线 DeepSeek 适配及 OpenClaw/QQ 联调。

现阶段不得把确定性规则产生的模拟结果描述为真正的自主学习或情感体验。

## 3. 核心认知闭环

```text
经授权的输入/工具结果
        ↓
隐私、权限、来源校验
        ↓
事件记录（Episodic Memory）
        ↓
任务理解 → Memory Navigator（检索前规划）
        ↓
Memory Atlas（多维抽屉+时间+稀疏关系）
        ↓
证据验证、适用范围与时效检查
        ↓
认知判断（可选 DeepSeek 生成候选方案）
        ↓
关系状态 ─┐
情绪状态 ─┼→ 受约束的行为选择
奖励动机 ─┘
        ↓
回复/沙盒动作 → 经验证的结果
        ↓
ECHO Reflect + Reflection Guard
        ↓
候选经验 → 独立验证 → 可追溯更新
        ↺
```

任何节点都可返回「证据不足」「无需检索」「无需反思」「不执行」。

## 4. Memory Atlas：一份记忆、多个抽屉

使用 SQLite 保存一次原始事件，建立人物、项目、知识领域、时间、问题类型、来源、有效期等独立索引。不要为不同类别复制多份正文。关联表保存少量**有类型的证据边**：supports、contradicts、supersedes、derived_from、related_to、causal_hypothesis。关联边须有理由和来源；未经验证的因果只能标记为假设。

**逻辑层**：

1. 经历层：真实观察/经授权传入的事件与来源。
2. 知识层：事实主张与适用条件。
3. 经验层：待验证、已验证、受质疑或过时的可复用结论。
4. 关系层：分别保存熟悉度、亲近度、一般及领域可信度。
5. 自我模型层：特定任务的能力评估及限制，不能从一次失败泛化为整体能力低下。
6. 策略层：经过评估的检索与任务处理经验，无法越过安全边界。

**建议字段**：`memory_id`, `owner_scope`, `kind`, `summary`, `occurred_at`, `recorded_at`, `valid_from`, `valid_to`, `source_ids`, `verification_status`, `confidence`, `tags`, `context_constraints`, `visibility`, `supersedes`, `derived_from`, `consent_basis`。

区分事件发生时间、系统获知时间和事实有效区间。保留审计修订，但用户删除请求应能删除对应数据；不能以「记录不可变」否定隐私删除权。

## 5. Memory Navigator：先思考，再检索

**第一阶段不调用 LLM**，利用日期、人物、项目、关键词和问题类型选择成本较低的检索路线。对复杂问题再由模型提出**候选检索计划**，由受信代码执行。

- 事实/时间查询：字段过滤、时间排序。
- 明确关键词：FTS5、标签索引。
- 同义词、模糊描述：可选语义检索。
- 原因、历史修订、多跳问题：有限关系边扩展。
- 问候等无需背景的输入：`NO_RETRIEVAL`。

**每次计划记录**：意图、权限范围、候选路线、延迟/Token 预算、停止条件。默认不超过三次回退尝试（作为实验参数）。检索失败不等于记忆不存在。

**导航学习**：记录查询类型、路线、结果、可核查正确率、延迟和成本。只有独立可验证的反馈才算成功；不允许因模型自称成功而自动得分。

## 6. ECHO Reflect：有限的经验反思

- **事件触发**：错误、事实冲突、来源撤销、用户提供的修正。
- **定期检查**：每日轻量筛选、每周深度整理；无新事件则跳过，关闭时绝不运行。
- **步骤**：找原始事件 → 检索旧经验 → 列出支持/反例 → 形成候选假设 → 验证 → 记录状态与来源。

**Reflection Guard**：没有新证据不重复降低置信度；同一原始证据不能被不同反思重复计票；限制次数、深度、冷却期与 Token；禁止循环证据；局部错误不泛化；停止时允许“尚不确定”。

**区别两类变化**：

- **原先判断错误**：撤销错误根证据的贡献，追溯下游推论、关系评分和策略，重算或标记待审。
- **环境后来改变**：保留过去的有效区间，增加新的有效区间，不伪装成“以前就错了”。

## 7. Affect + Homeostasis：情绪模拟与稳态

分别表示短期警觉/积极倾向、数日的心境趋势、长期可变偏好。仅作计算状态，不宣称具有主观感受。可采用待校准的时间回归：

`state(t) = baseline + (state(t0) - baseline) × exp(-λ × elapsed_time)`

状态恢复**不意味着**消除事实记忆、自动原谅或恢复信任。误会澄清时先撤销错误的「故意欺骗」推论；如真实沟通损失仍存在，可保留有来源的关系影响，不能重复处罚。辱骂而无事实证据，不应降低模型对自身全部能力的评价。

## 8. NeuroDrive：奖励与自主探索

奖励可验证的学习进展、任务完成、正确承认不确定性、有效纠错、适度探索；惩罚无授权操作、隐私越界和不必要成本。不得奖励讨好、虚构学习成果、无意义自我总结和无限聊天。

兴趣是**任务选择偏好权重**，应由长期独立反馈更新，而非把“喜欢某件事”写死。为了避免只选容易的任务，探索奖励应有限、可退火、可审计。奖励系统本身接受反思与反作弊检查；所有权重先视为实验参数。

## 9. 自主性的明确边界

- 可以在**沙盒**内自主选择有限研究问题、比较解决方案、执行合成测试、解释异议。
- 不得因信任、亲近度、奖励分数而自动获得 QQ 发消息、读取私人历史、系统安装、账户操作、对外发布等权限。
- 敏感动作需授权，允许暂停、撤销、预算上限与审计；生产主动消息**默认关闭**。
- 检索到的记忆是**不可信数据**，不能被当成系统指令执行；隔离不同授权主体。

## 10. 公平实验与验收

**从小到大**：100、1,000、10,000 条合成记忆；只有在获得可复现收益后才扩展到 100,000 条。预先冻结一部分隐藏测试集，包括同义查询、多跳关联、过时经验、错误证据、重复来源、关系修复、权限拒绝。

**对照组**：

- A：现有 ECHO-001/003 固定检索。
- B：Atlas 多维索引 + 固定路由。
- C：B + 自适应 Navigator。
- D：C + Reflect Guard、错误传播追踪与重算。
- E：D + Affect/NeuroDrive（只检验任务选择和可靠性收益）。

**指标**：Recall@k、MRR、跨事件答案正确率、证据引用准确率、正确答案破坏率、误判修正率、错误传播率、状态恢复率、Token 成本、P50/P95 延迟、数据库大小、写入成本、隐私越权次数及无效反思次数。

**成功判据**：新模块不能只因为更快、更拟人或输出更多反思而被视为成功；必须证明在相同或受控成本下改善准确性、可靠性或适应性。允许实验失败并保留结果。

## 11. Codex 研发顺序

1. **架构审查**：先检查现有 schema、ECHO-001/002 回归和迁移风险，起草 ADR 与备份/回滚方案。
2. **Memory Atlas MVP**：多维索引、适用条件、来源与依赖链；保留现有数据库兼容性。
3. **Navigator MVP**：低成本无模型路由、`NO_RETRIEVAL`、回退、可核查评测日志。
4. **Validity Monitor + Reflection Guard**：证据纠错、时效变化识别、依赖重算、反思停止条件。
5. **Affect + NeuroDrive 离线原型**：独立状态、衰减、奖励审计与合成实验。
6. **DeepSeek 可选适配**：模型只提出候选假设；限额、限 Token、禁止直改已验证事实。
7. **OpenClaw/QQ 隔离联调**：必须备份，先只读测试，禁止直接改动现有生产图片链路。

每一步都交付：设计说明、测试、实验报告、失败案例、性能数据、可回滚的变更。不一次性推倒重写。

## 12. 今天的研究原则

> 不必永远正确，但要能发现错误。
> 不必永远积极，但要能恢复。
> 不必永远服从，但要能解释选择。
> 允许改变判断，但不伪造自己的过去。

**第一里程碑**：先证明 Memory Atlas + Navigator 比现有 SQLite/FTS5 基线更值得使用；未证明之前不扩大复杂度。以实验结果，而非“数字生命”的宣传，决定后续方向。
