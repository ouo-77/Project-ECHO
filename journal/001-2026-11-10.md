# Journal 001 — Memory before personality

**Date:** 2026-11-10  
**Phase:** 01 / first prototype  
**Visibility:** public milestone summary

### Hypothesis

Long-term continuity can be evaluated more reliably if the agent's records are persistent, readable, privacy-classified and correctable before any attempt to simulate emotional states.

### Implemented

- SQLite-backed event-like memory records with source labels and timestamps.
- Local keyword search ranked by importance and recency.
- Corrections that retain a link to an earlier assertion.
- Explicit deletion and public-only export.
- Automated tests for continuity, revision and privacy.

### Not yet implemented

- DeepSeek integration or automatic extraction from chats.
- OpenClaw/QQ integration, emotion models, autonomous action or self-modification.
- Evidence of subjective experience.

### Next experiment

Run the test suite on a separate machine, create a non-personal 20-item memory benchmark, measure retrieval precision and false recalls, then evaluate whether more expensive semantic retrieval is justified.

**Status:** source code prepared; real-world deployment and benchmarks are pending.
