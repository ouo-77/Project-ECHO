# 2026-11-10 · 独立记忆接口验收

远端初始化时没有分支、标签或已有提交。以 Phase01 包的 6 项测试为基线，在 Windows 和 Python 3.12 上通过后扩展了记忆接口。

同一事实键收到第二个值时，数据库保留当前值，并返回冲突记录的 ID。确认修订后仍可按 ID 查到原记录。两个调用者同时修订同一版本的测试中，只有一个后继写入成功。

经验与反思通过记录 ID 相连。检索测试验证了中文关键词、排序、字符上限和独立数据库隔离。重启测试通过两个独立的 Python 进程写入和读取同一文件。完整套件共 11 项，命令为 `python -m unittest discover -s tests -v`。

这些实验验证了记录、修订和取回经验的能力。自主提炼经验的质量以及真实 QQ 场景下的行为变化仍待测量。
