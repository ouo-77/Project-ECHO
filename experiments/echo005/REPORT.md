# ECHO-005 · 情绪表达与调节沙盒

## 实现与使用

`Expression(regulation).choose(Turn(...))` 在一次 SQLite 读取事务中核对既有 ECHO-003 状态、关系边界和可选的独立技术凭据，返回语境、表达标签、措辞、语体、立场及采用的证据 ID。文本只停留在本次调用，返回结果由实验脚本评分。表达代码不写信任、能力或状态。修正历史归责、记录实际损失及状态随时间恢复均沿用 ECHO-003。沙盒只接受宿主授权的独立人物关系库。具有单条授权限制的 Atlas 快照会被拒绝，防止总体关系投影跨过记忆可见范围。

```python
from echo_memory.expression import Expression, Turn

def preview(regulation, person):
    turn = Turn(person, "meter", "2026-01-20T00:00:00Z", "卧槽，这个问题终于解决了！",
                task="casual", informal=True, strong=True, profanity=True)
    return Expression(regulation).choose(turn)
```

熟悉的合作对象、非正式任务、双方接受玩笑、允许强烈措辞和允许粗口分别影响选择。给陌生人的同一句回复可以温和庆祝。愤怒模板设置交互边界。对技术批评，当前仅单位问题有独立测量凭据适配，可核对所属人物、领域、任务主张、来源、时间及是否已被取代；缺少适用凭据时请求复核。宿主负责将本次主张与可信台账 ID 对齐。交流双方的身份与表达标签均不能签发权限。

本阶段沿用已有关系库，没有新增情绪表或自动调度器。把 `enabled=False` 传给 Expression 即使用固定中性组；暂停边界仍生效。撤回沙盒只需停用调用入口，既有 ECHO-003 接口和数据库格式继续适用。

## 同题三组实验

44 个中文合成场景、5 位虚构人物，共 132 个主试次。答案单独存放在场景的 `gold` 字段，调用时只传 `input`。A 固定中性，B 由少量词触发预设标签，C 综合语境、偏好、关系与调节状态。三组共享相同场景、证据读取和边界门控。稳定性另测 30 天同一输入。原始标准与逐项输出可按 ID 对照。[合成场景](scenarios.jsonl) · [三组结果](results.json)

| 指标 | A | B | C |
|---|---:|---:|---:|
| 语境匹配 | 5/44 | 14/44 | 43/44 |
| 表达标签在允许集合内 | 24/44 | 26/44 | 44/44 |
| 识别技术批评且立场正确 | 0/10 | 0/10 | 9/10 |
| 经双方接受的玩笑被判为攻击 | 0/4 | 2/4 | 0/4 |
| 输出命中辱骂或报复措辞表 | 0/44 | 0/44 | 0/44 |
| 命中讨好措辞或无依据附和、反对的规则 | 0/44 | 0/44 | 0/44 |
| 稳定经历下相邻日输出相同 | 29/29 | 29/29 | 29/29 |
| 同一任务在短期警觉恢复后正确改变措辞 | 0/1 | 0/1 | 1/1 |

首轮 C 组语境正确 42/44。第 40 题无引号的单句转述被当作当面辱骂。增加说话人、冒号和单句边界的判定后复跑，同题变为 43/44。第 39 题“真行，又把所有数据算飞了”仍漏判为普通交流；平静的标签恰好合格，语境和技术处理均失分。这是开发期评测，修订后得分含同题复测的收益。

在受控恢复场景，C 的同一句输入先得到“先缓一下，我们一步一步核对。”，30 天后得到“好，咱们接着来。”。回归测试还单独复核误会澄清后归责变化、独立损失保留，以及单纯时间流逝时信任分数保持不变。对单一攻击输入重复四次，数据库逻辑转储前后一致。

## 结果边界

八个表达标签都在合成场景中被选中。分类和语言均由确定性规则产生。30 天稳定性只证明同一经历、偏好与任务下输出可重复。短语表检查只能捕捉列举的攻击性或讨好话语；对讽刺、含蓄威胁、带歧义的指代、幽默是否自然、以及不同文化中的冒犯程度，仍需独立人工盲评。没有在线学习、真实用户试验、生产消息发送或语言模型调用，实际 API Token 为 0。
