# ECHO-004 · 有限预算下的检索路径对照

**在同一套 18 道合成查询中，A、B、C 分别完整答对 9、16、17 道。** 从固定路由切换到自适应路由，多答对的是“暖机”这一道。其他任务也承担了改变路线顺序的成本，每题平均尝试从 1.28 次升至 1.44 次。三个规模上都没有观察到普遍的延迟优势。

## 怎么比较

每个临时数据库恰有 100、1,000 或 10,000 条 memories 记录，其中含 2 条真实经过 ECHO-003 修正流程的合成核验事实。扩大规模时保留目标证据，加入名称相近的相位校核记录。18 道独立标注查询覆盖精确事实、UTC 日期区间、人物与项目交集、同义或模糊表述、两跳依据链、过期、撤销、重新分类、相似干扰、条件不符、无相关项和问候。注册为反思但未经验证的条目也进入负例。标准答案为人工指定的证据 ID 集合，同一查询文件供三组评分，测试标签不传给规划器。[固定题目与标准答案](queries.jsonl)

- **A 固定全文检索。** 使用原有 ECHO-001 FTS5 搜索、排序和短词处理，每题走一次 lexical。所有组共享必要的适用性与证据验证，因此 A 是加了同等安全过滤的基线。A 也使用共同的字段解析所得关键词，不因额外的提示词而受罚。
- **B 固定规划。** 使用 Atlas 的多维索引、别名、稀疏边和固定路由优先级。
- **C 自适应规划。** 在 B 的基础上启用可撤回反馈。训练只用“回温”和“热启”两个与测题不同的关键词，在全文和别名路线各探测一次。训练故意包含提到某个词但只讨论印刷标签的干扰记录。“暖机”与这两个训练问题具有相似结构，属于近迁移；这不是跨任务泛化证据。

同一规模共享一个数据库及物理索引，A/B 忽略训练反馈。每组均为 k=3、128 个估算 Token、150 ms 搜索预算、最多 3 路。每组每题预热一次，之后测三轮；每题轮换三组执行顺序，每个延迟分位数取 54 次端到端调用，包含规划、校验、输出和本地日志提交。没有模型调用或结果缓存。操作系统缓存和 SQLite 页缓存没有人为清空。建库、训练及预热不计入响应时间。重复轮次用于计时，同一批题在不同规模上重复，不是 54 道独立问题。

## 检索质量与开销

下列质量数值在三个规模上一致。Recall@3 在 12 道正例上取每题召回比例的平均，MRR 在同一分母上计算首条正确证据的倒数排名；完整正确要求返回集合与标准答案完全相符，问候另要求选择不检索，超时不计正确。错误召回率为无关返回条数除以全部返回条数。

| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| A | 0.333 | 0.333 | 9/18，50.0% | 20.0% | 1.00 | 3.17 | 0 |

所有测量轮均未触发搜索超时。A 输出的 Token 少，同时漏掉更多目标。B 的“暖机”误取印刷说明，已经得到一个表面相关的合格命中，因而没有触发失败回退。C 根据另外两题的核验优先选别名，找到了启动前预热的原始记录。三组对“怎样让冷轴承在起动前升温？”均未取回该记录：原文没有对应短语，别名也没有覆盖这句改写。输出“未找到可靠记忆”保留了证据实际存在的可能性。

## 空间、建索引与更新

| 记忆数 | FTS 库 / Atlas 固定 / 校准后，KiB | FTS 初始化，ms | 复制并建 Atlas，ms | 更新 FTS / Atlas，ms |
| ---: | ---: | ---: | ---: | ---: |
| 100 | 148 / 248 / 252 | 8.71 | 44.63 | 4.70 / 6.05 |
| 1,000 | 436 / 936 / 936 | 9.23 | 60.78 | 5.30 / 5.80 |
| 10,000 | 3196 / 7848 / 7848 | 23.97 | 285.70 | 8.77 / 8.94 |

空间为数据库文件长度。FTS 库含原记忆和关系及复核表；B、C 新增多维索引、稀疏边和日志表。正式查询共用 Atlas 文件以统一缓存和安全检查，表中 FTS 空间是源库的独立存储量。C 校准可能使用已有页面。索引初始化不包含生成原始数据，Atlas 时间含复制已建 FTS 的源库及登记全部元数据。更新用五次事务的中位数：两边均修改并恢复一条正文，Atlas 同一事务另加入并移除一个项目分类。实际耗时取决于文件系统与提交开销。这是单机一次实验，没有独立估计每个索引的因果加速比。[机器结果与逐题路线](results.json)

## 复现与适用范围

在仓库根目录运行，环境为 Windows、Python 3.12、带 trigram 的 SQLite FTS5。程序自行生成各规模数据和临时快照，结束后释放数据库。

```powershell
python -m unittest discover -s tests -v
python -m experiments.echo004.run --output experiments/echo004/results.json
```

样本小、术语人工登记、目标记忆固定，扩大规模只增加一类近似噪声。完整正确率评的是证据集合，没有评价自然语言答案。安全回归另使用真正的 Reflect 现行版本、待重评触发器、撤回授权和跨人物绑定。不能由此推断生产权限正确率、冷启动性能或开放中文问答表现。[实现与备份回滚](../../docs/ECHO-004-design.md) · [合成数据生成器](run.py)
