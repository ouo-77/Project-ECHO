# ECHO-003 · 三组离线实验

所有实验使用全新、按虚构人物隔离的 SQLite 数据库。策略预测结果与后续独立合成检验比对；所有百分比都以实际分母计算。公开文件包含合成输入、逐题预测和证据链，不含运行时数据库。

## 认知修正

固定种子 3003 生成 8 人、2 个领域、6 阶段、共 384 条经历。每人每阶段每领域进行 3 次独立合成通过/失败检验，共 288 次。原始观测与检验结果采用不同的随机数流。部分人物的计量能力在后半程提高，以检验关系修复。评价包含技术错误、误解、故意欺骗、整条撤销和相互矛盾的多来源证据。原顺序与阶段内留出乱序使用相同内容和答案；留出种子 73193，没有把未来阶段的核验提前。固定基线与修正版使用完全相同的分数阈值、至少两条正向来源要求及更新参数，唯一区别是基线沿用原标签。关闭记忆时从中立状态出发，总是复核。

| 处理方式 | 原顺序准确率 | 留出顺序准确率 | 原顺序过度信任：失败却建议试验 | 原顺序过度怀疑：通过却要求复核 |
| --- | ---: | ---: | ---: | ---: |
| 固定参数、沿用旧标签 | 139/288，48.3% | 139/288，48.3% | 7/129，5.4% | 142/159，89.3% |
| 核验后重放 | 219/288，76.0% | 222/288，77.1% | 18/129，14.0% | 51/159，32.1% |
| 关闭经验记忆 | 129/288，44.8% | 129/288，44.8% | 0/129，0% | 159/159，100% |

每种顺序有 153 次修正。43/43 次整条撤销后，所有内部状态逐项等于在当前位置省去错误事件的参考重放。48/48 个人物阶段末状态等于按正确标签重放的状态。153/153 次可由原始贡献重建修正前后分数与策略，153/153 次保留另一领域判断。原顺序 96 个人物阶段领域探针中，66 次同时有正反证据。例如复核 `sim-00-4-0-0` 后，“知情虚报”改为“复测通过”，计量判断由 0.632 升至 0.715，策略从复核变为沙盘试验。完整记录保留原始依据、推翻它的事实和其余反证。[原顺序结果](results/listed.json) · [乱序结果](results/heldout.json)

在潜在能力固定的 42 次后期阶段转换中，原顺序修正版平均分数绝对漂移 0.050，切换策略 4 次；基线为 0.046、2 次。准确率提高的同时，过度信任和后期波动也有所增加。另在 120 次连续模拟中，于第 101 次插入一个异常负例，最后 60 次策略均保持试验；最初只有一个正例时仍要求复核。这不能排除接近阈值时单个事件改变判断的可能。

## 时间调节与重评价 A–H

| 实验 | 观测 |
| --- | --- |
| A 自然回归 | 初始短期激活 0.8，七天后为 0.00625。三种尺度在第七天分别保留其初值的约 0.78%、50%、85%。 |
| B 平复与信任 | 同一事件三十天后短期激活接近零，领域信任仍为 0.333。 |
| C 澄清误会 | 新的任务书证据使领域信任从 0.333 回到 0.500，半日时短期激活仍约 0.226。 |
| D 保留实际损失 | 同样澄清，同时存在独立损失记录时，领域信任同为 0.500，短期激活约 0.42，亲近度约 0.21；无损失对照约 0.46。随后用另一条核验撤回澄清，旧时点的判断仍可回查。 |
| E 严重损失与边界 | 第 60 天仍为暂停交互。已单独登记宽恕，关系修复状态仍为未决。 |
| F 可靠经历后的修复 | 十次独立补救后信任约 0.70，双方另行同意后登记关系修复。有限交互边界继续要求复核，宽恕仍为未决。 |
| G 再激活 | 第 14 天出现同类事件时短期激活从接近零回到约 0.80。另一领域的事件没有被计入。 |
| H 参数对照 | 同一输入经过两天，短期半衰期 1 天和 4 天分别产生 0.200 和 0.566，落入普通与放慢核查两种节奏。两组信任相同。 |

A、B、H 的差异由时钟及预设参数决定。C、D 的归责变化需要新增核验事实，E、F 的关系选择需要另行记录，G 依赖新事件。跨进程测试用相同时刻重建了相同状态，也验证了默认使用当前 UTC 时间。[所有输入及逐案输出](results/regulation.json)

## ECHO Reflect 的隐藏任务

53 条有授权的训练或独立核验经历，覆盖 8 个已见领域/工序组合。训练经历提出方向，独立核验与反例决定能否取用。40 个新任务的容差事先固定为 4 微米，独立合成台架测量误差在容差内视为可试验。评分表与任务文本分开；程序完成修正前、修正后和关闭反思三遍预测后才读取测量表。评分表随仓库公开，以便复现；“隐藏”指它对本次预测流程不可读作输入，并非秘密测试服务。[任务](reflect/tasks.jsonl) · [评分表](reflect/heldout_measurements.jsonl) · [评分程序](reflect/run.py)

| 条件 | 正确任务数 |
| --- | ---: |
| 修正前，启用反思 | 25/40，62.5% |
| 修正后，启用反思 | 29/40，72.5% |
| 同一修正后关系库，关闭反思 | 25/40，62.5% |

- **A、B、C、E**：同类重复失误形成复核建议。独立复算推翻 warm-start 的通过记录后，依赖该证据的旧版本立即改为待重评。8 次失效窗口探针中，过时建议被返回 0 次（错误传播率 0/8）。重评修好了全部 4 个目标误判；按所有原先错误计算，错误修正率为 4/15（26.7%），新增错误 0 个。
- **D、I**：只从原始关系事件表接纳证据。重复总结相同批次没有生成新版本或提高置信度；人工批准和模型自述均不能充当核验经历。53/53 条既定依赖可回查原始来源、核验分区和复核引用。
- **F、G**：不同领域同名工序、未见工序、训练与核验冲突、证据不足及高风险未批准时，经验建议为空。此时走相同的领域基线，高风险任务默认复核。11 个最终误判说明范围匹配或拒绝给建议都不能保证任务正确。[逐题记录与能力评估](results/reflect.json)
- **H**：跨进程重启后，每日额度没有重置，已验证的工序状态可恢复。失败重试、暂停、禁用、重大事件触发和独立人审通过自动化测试。

本机测量 200 次建议检索，中位数约 1.34 ms，P95 约 1.68 ms；一次深度重评约 5.97 ms。40 个任务总计 536 个估算上下文 Token，计入实际返回的建议文本，使用 ECHO-001 的估算器。API 调用与计费 Token 均为零。

## 局限和复现

三组实验复用确定性规则。核验者和同意记录都是合成输入，无法验证真实动机、来源真实性、主观体验或机器意识。训练与独立核验指不同记录分区，并非多个真实机构的独立复核。指标受虚构样本构成、误标比例、阈值和错误成本影响。当前实现按小库扫描和重放，未测试大库、跨设备时钟差异或生产访问控制。周期按成功产生新版本的时点计；空闲扫描仍有读取成本。未测真实模型的语言理解和计费 Token。

在 Git 工作副本根目录运行，依赖 Python、标准库 SQLite（含 FTS5 和 JSON）。每个命令都使用独立临时库。

```powershell
python -m unittest discover -s tests -v
python -m experiments.echo003.run --output experiments/echo003/results
python -m experiments.echo003.regulation_cases --output experiments/echo003/results/regulation.json
python -m experiments.echo003.reflect.run --output experiments/echo003/results/reflect.json
```
