## 结论与复现

在新的 229 道中文问题中，151 道可回答题只有 10 道返回了完整证据。综合表达策略通过 30/40 个新场景。万条记忆实验中，重要原文非授权损失为 0/6,000，删除验证证据后，路径检查经验立即停止提供正式建议。旧运行时和修复版在同一语言留出集上的汇总得分相同。修复的效果由可以在旧版复现的证据、事务及权限边界用例验证。

按 Git 历史分开冻结题面与实现。题库与协议提交为 `c17492a`，评分器和待测代码为 `b2ae6ea`，原运行时为 `be28878`。最终验证后仅增加复现材料、实测结果和文档。旧版对照在独立临时目录中运行相同的冻结评分器。所有人物、记忆、凭据及话语均为合成。本项目成员编写题面和答案，能接触旧项目说明；独立性来自未参与调参、事前冻结和原始输出可查。没有外部出题或双人盲标。[冻结协议](PROTOCOL.md)

## 生命周期、空间与检索成本

在全新源库生成 10,000 条可逐字核对的事实，复制至按所有者绑定的 Atlas。L0、L1 各 2,000 条，L2 共 4,000 条，L3 共 2,000 条。两个线程各使用独立连接，每批最多处理 200 条。预期的 4,000 条到期低价值正文及对应 FTS 行全部清除，另有 2,000 条 L2 归档，归档探针未进入正常检索。比较全部重要正文，6,000 条均与生成时逐字相同。异域状态探针只看到 UNKNOWN，异主打开被拒。子进程重启后，分级、到期日、归档标志、分类理由的全表摘要与父进程一致。清理前的 SQLite 备份可独立重新打开并恢复查询，源库哈希未变；活动库外键检查与完整性检查通过。[原始计数与检查](lifecycle_results.json)

| 指标 | 清理前 | 清理后 |
|---|---:|---:|
| 正文字节 | 850,000 | 510,000 |
| SQLite 主文件字节 | 10,330,112 | 11,923,456 |
| 可复用空闲页字节 | 0 | 1,851,392 |
| 同一批核心定位查询 | 20/20 | 20/20 |
| 上述查询估算 Token | 580 | 580 |
| 上述查询 P50（ms） | 5.44 | 8.58 |

正文减少 40%，文件增长约 15.4%。实验保留了遗忘凭据、查询审计和 FTS 存储结构，没有执行 VACUUM。两次检索顺序固定，20 次样本不足以断定清理会提高或降低查询速度。这里核对的是活动库的逻辑索引，不涉及磁盘取证级清除或备份副本销毁。

**摘要的实际代价。** 七条独立输入共 959 字节，仅输出建议文本为 78 字节。将适用条件、证据 ID 及来源、类型和置信度一同序列化后为 628 字节，相对原文节省 34.5%。七条原始证据此时仍在，不产生等额磁盘节省。去掉“只读演练”条件或超过有效期，均读不到有效建议。反复整理同一批证据未增加权重。明确删除一次独立成功试验后，旧版本立刻停止输出，重新计算降为候选；复用同一 ID 写入无关事实后仍为候选。这里验证了结构化条件，没有证明系统能识别藏在自由文本中、未经登记的关键条件。

- 28–29 针对同一人物，在形成共同经历前后，普通交流由正式变为口语。30–31 在时间恢复前后从谨慎核对转为普通节奏。32–33 在独立澄清证据出现前后发生相应变化。已有回归另测真实损失依据仍存在时的保留行为。

## 代码审查与验证边界

| 审查项 | 可复核的处理与边界 |
|---|---|
| 事务、并发、回滚 | 分类和清理持有 SQLite 写事务。注入第二条删除失败，先前删除、FTS 和遗忘凭据随事务回滚。双线程扫库无重复处理。未测试断电、损坏介质或分布式并发。 |
| 证据撤销 | 纠正凭据缺失或被取代时，投影停止消费该判断。Reflect 将依赖该凭据的版本置为待复核。新测试从已验证状态经删除重算到证据不足。失效的损失凭据退出投影，失去边界选择的凭据时维持暂停，直到另有有效选择。 |
| 遗忘凭据与适用域 | 原有多域凭据检查继续生效。纠正事实也重新检查原事件的全部授权域、条件及归档状态。域名、条件和身份由受信宿主提供。 |
| 删除与索引 | 删除 Atlas 目标时撤销直接依赖项，清除指向目标的边，再用旧 ID 登记新材料无法激活旧结论。打开旧工作副本时清理可检测的悬空边。迁移前已经复用且缺少历史快照的 ID 无法单凭当前库复原。审计历史有单独保留周期。 |
| 核心记忆 | 明确保留已归档条目可提升为可用 L3。现有修订入口可换成新的核心事实，显式删除新事实后旧版未重新进入 Atlas 决策。 |
| 反思与压缩 | 带有已声明依赖边或反思版本的记录不能以独立试验身份进入整理，读取时重验资格。独立性仍依赖来源如实标记，未建模伪造来源的攻击者。 |
| 否定与检索条件 | 语义路线仍须满足显式关键词。错误类型的条件容器会被拒绝。没有扩充同义词表；反问、多重否定和跨概念推断的失败保留在留出集中。 |
| 表达授权与实验隔离 | 布尔偏好采用严格类型，字符串不能意外开启强烈语言。语体规则无权授予外部操作。实验使用临时库、纯本地模板与独立源快照。无真实聊天或 API 调用。 |

11 个开发回归在旧代码上有 9 个测试方法失败，在审查版全部通过。部分方法包含多个断言，旧版在第一个失败处停止，因此不能把方法数解读为九个互相独立的漏洞。之前的 40 项回归继续通过。此阶段允许得分不变；语义覆盖、讽刺和多意图措辞仍是开放问题。[开发回归](../../tests/test_echo0051.py)
