# ECHO-005.1 冻结协议

起点为 Project ECHO 的 be28878。独立验证指这些数据在本次审查前写定，并且从未用于原版本的开发或调参。出题者能看到项目历史，未委托外部人员盲标。语料基于新写的虚构台账，无外部采样。为便于复查，在实现跑分器、修改运行时代码及首次查看预测之前用 Git 提交全部题面、上下文和标准答案。审查只使用另写的开发用例。最终结果无论高低均保留，不依据本集结果修改规则后再报独立分数。

## 检索

229 道不同中文问题，覆盖 26 条新记忆、7 个领域。前 208 题为逐条手写的语言变体、区分概念或未知题，15 题需要两个证据，6 题为字面控制。条件由虚构宿主作为任务上下文传入。标准答案是完成问题所需的证据 ID 集合。空集合代表没有足以回答问题的记忆。反问需返回能够判定命题真假的证据，而非默认拒答。按现行默认预算运行，模型只接收题面、领域和条件。全量记录返回 ID、状态、端到端时延和估算 Token。准确率为完整集合匹配，超时一律算错；错误召回同时报告含多余 ID 的题数及错 ID 占返回 ID 总数；拒答正确率按无答案题统计。报告联合题及可回答题的正确率，防止总分奖励一律拒答。时延报告 P50、P95。

## 表达

40 个场景采用已授权的单人沙盒。沿用 A/B/C 三种策略。标注允许多个合理标签，逐题同时考核语境、立场、语气、指定语体与节奏。谨慎指回复中明确提出核查或复核；普通节奏无需提出这些要求。对暂停要求空输出；只在亲近、已允许强烈口语的轻松场景接受粗口。相同语句的关系配对、调节恢复和澄清配对单独列出变化。固定模板的自然感仍待人工判断。

## 生命周期和审查

新建独立临时数据库。至少 10,000 条合成记忆，核对重要正文、到期清理、归档、跨域拒绝、原文及索引、原始证据与摘要的一致性。比较清理前后字节、占用页、文本保留比例及同一查询成本。单独比较摘要与原始输入的文本长度，记录原始证据是否仍保留。用新进程重开数据库，执行并发及失效回归，验证从 SQLite 备份回滚。标准为重要原文非授权损失、跨域披露及失效证据放行全部为零。出现失败逐项记录。
